### 🎮 GitHub Repository Description

**Tic Tac Toe — HTML, CSS & JavaScript**

A responsive and interactive **Tic Tac Toe game** built from scratch using **HTML, CSS, and vanilla JavaScript**. The project demonstrates core front-end development concepts including DOM manipulation, event handling, game-state management, conditional logic, and responsive UI design.

### ✨ Features

* 🎮 Two-player Tic Tac Toe gameplay
* ⚡ Real-time game interaction
* 🧠 Automatic win-condition detection
* 🤝 Draw/tie detection
* 🔄 Restart/New Game functionality
* 🎨 Clean and modern user interface
* 📱 Responsive design for different screen sizes
* 🚫 Prevents invalid moves after a cell has been selected
* 🏆 Displays the winning player when a game ends

### 🛠️ Technologies Used

* **HTML5** — Structure and game board
* **CSS3** — Styling, layout, animations, and responsive design
* **JavaScript (ES6+)** — Game logic, DOM manipulation, event handling, and state management

### 📚 What I Learned

While building this project, I practiced:

* DOM manipulation
* JavaScript event listeners
* Arrays and game-state management
* Functions and conditional statements
* Handling user interactions
* Creating reusable game logic
* CSS layouts and responsive design
* Debugging and organizing front-end code

### 🚀 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing! 🎮

No external libraries or frameworks are required.
