# 🎮 Tic Tac Toe — JavaScript

A responsive and interactive **Tic Tac Toe game** built from scratch using **HTML5, CSS3, and Vanilla JavaScript**.

This project focuses on implementing game logic, managing application state, handling user interactions, manipulating the DOM, validating player moves, and creating a clean responsive interface — making it a practical project for strengthening core front-end development skills.

---

## ✨ Features

* 🎮 **Two-Player Gameplay** — Play locally with another player.
* 🧠 **Automatic Win Detection** — Detects horizontal, vertical, and diagonal winning combinations.
* 🤝 **Draw Detection** — Automatically identifies when the board is full without a winner.
* 🚫 **Move Validation** — Prevents players from selecting an already occupied cell.
* 🔄 **Restart Functionality** — Quickly reset the board and start a new game.
* ⚡ **Interactive Gameplay** — Game state updates instantly based on player actions.
* 📱 **Responsive Design** — Designed to provide a smooth experience across different screen sizes.
* 🎨 **Clean User Interface** — Simple and focused game layout.
* 🧩 **Vanilla JavaScript** — Built without external frameworks or libraries.

## 🎯 How the Game Works

The game follows the traditional Tic Tac Toe rules:

1. Two players take turns making moves.
2. Each player selects an available cell on the 3×3 board.
3. The game checks the board after every move.
4. A player wins by completing a valid horizontal, vertical, or diagonal combination.
5. If all cells are occupied without a winner, the game ends in a draw.
6. Players can restart the game to begin another round.
